## 📡 ILATTP — I Love Anna Text Transfer Protocol

Первый готовый компонент проекта. ILATTP — это текстовый протокол прикладного уровня, позволяющий обмениваться сообщениями между клиентом и сервером. Каждое сообщение — это строчка, пронизанная любовью.

**Ключевые особенности:**
- Простой текстовый формат.
- Лёгкая реализация на любом языке.
- Название — дань уважения Анне.

Подробное описание, спецификация и примеры использования находятся в папке [`ilattp`](./ilattp/).

Быстрый старт:

    # Клонирование репозитория
    git clone https://github.com/yourusername/ILA-Project.git
    cd ILA-Project/ilattp

    # Запуск сервера (пример для Python)
    python3 server.py

    # В другом терминале — клиент
    python3 client.py

Пример сессии:

    Client: HELLO I Love Anna
    Server: 200 I love Anna too
    Client: SEND Как прекрасен этот мир, когда ты рядом
    Server: 250 Message received with love
